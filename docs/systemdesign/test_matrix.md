# Test Matrix

This matrix links each test suite to the architectural responsibilities
documented in `module_reference.md`. It should stay in sync with the fixtures in
`tests/support` and with the public API guarantees.

| Suite                                                  | Focus                                       | Key Modules                                                                                                 | Notes                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
|--------------------------------------------------------|---------------------------------------------|-------------------------------------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `tests/unit` / `tests/domain`                          | Domain and pure functions                   | `lib_layered_config.domain.*`, `observability`                                                              | Validates immutability, provenance helpers, and logging utilities without hitting I/O boundaries.                                                                                                                                                                                                                                                                                                                                                       |
| `tests/application`                                    | Merge policy and functional invariants      | `lib_layered_config.application.merge`                                                                      | Uses property tests to ensure associativity, precedence, and metadata stability.                                                                                                                                                                                                                                                                                                                                                                        |
| `tests/adapters`                                       | Adapter contracts and boundary coercion     | `lib_layered_config.adapters.*`                                                                             | Contract tests rely on `tests.support.layered` to keep platform-specific scaffolding declarative.                                                                                                                                                                                                                                                                                                                                                       |
| `tests/examples`                                       | Example helpers and deployment tooling      | `lib_layered_config.examples`                                                                               | Unit tests for backup/UCF file creation, numbered suffixes, conflict resolution callbacks, and filesystem layouts.                                                                                                                                                                                                                                                                                                                                      |
| `tests/e2e`                                            | Composition root and CLI behaviour          | `lib_layered_config.core`, `lib_layered_config.cli`                                                         | Exercised via end-to-end scenarios; notebook execution is marked `slow`.                                                                                                                                                                                                                                                                                                                                                                                |
| `tests/e2e/test_cli.py`                                | CLI command integration                     | `lib_layered_config.cli`                                                                                    | Tests read/deploy/generate commands, JSON output, and provenance formatting.                                                                                                                                                                                                                                                                                                                                                                            |
| `tests/e2e/test_deploy_behavior.py`                    | Deploy conflict handling                    | `lib_layered_config.examples.deploy`, `lib_layered_config.cli.deploy`                                       | End-to-end behavior tests for first-run creation, batch UCF creation, force overwriting, numbered backups, smart skipping (identical content), and JSON output structure.                                                                                                                                                                                                                                                                               |
| `tests/e2e/test_notebooks.py`                          | Documentation parity                        | `notebooks/Quickstart.ipynb`                                                                                | Executes notebook cells (skipped on macOS because of path leakage) to ensure tutorials stay in sync.                                                                                                                                                                                                                                                                                                                                                    |
| `tests/domain/test_deploy_mode.py`                     | Deploy mode safety rule                     | `lib_layered_config.domain.deploy_mode`                                                                     | `DeployMode`/`parse_mode_text`: the one rule for a permission mode the deploy path may apply (range, special bits, group/world write, owner bits, execute-on-file).                                                                                                                                                                                                                                                                                     |
| `tests/domain/test_deploy_permissions.py`              | Configured permission section reading       | `lib_layered_config.domain.deploy_permissions`                                                              | `[lib_layered_config.default_permissions]` validated in one pass: per-layer modes, `enabled`, unknown keys, and runtime `overrides=` laid over the configured values.                                                                                                                                                                                                                                                                                   |
| `tests/adapters/test_env_scalar_coercion.py`           | Environment scalar coercion                 | `lib_layered_config.adapters.env.default`, `adapters._value_coercion`                                       | The environment layer turns a value into a number only when the number reads back as the same text; boolean/null coercion and the values that stay strings.                                                                                                                                                                                                                                                                                             |
| `tests/adapters/test_loader_errors.py`                 | Content-free loader errors                  | `lib_layered_config.adapters.file_loaders.structured`, `adapters.dotenv.default`, `adapters._text_decoding` | A file that cannot be decoded or parsed raises naming the place (path, format, line/column or byte offset), never the content.                                                                                                                                                                                                                                                                                                                          |
| `tests/examples/test_deploy_modes.py`                  | Explicit dir_mode/file_mode on disk         | `lib_layered_config.examples.deploy`                                                                        | Explicit `dir_mode` / `file_mode` through `deploy_config`, on a real filesystem: applied, refused when unsafe, and how a partial override resolves the other side.                                                                                                                                                                                                                                                                                      |
| `tests/examples/test_deploy_configured_permissions.py` | Configured permissions on disk              | `lib_layered_config.examples.deploy`                                                                        | Configured `[lib_layered_config.default_permissions]` through `deploy_config`, on a real filesystem: read from the source/app/host/user files (a user file's `app_*`/`host_*` ignored), never `.env`, and refused when unreadable or invalid.                                                                                                                                                                                                           |
| `tests/examples/test_deploy_public_read.py`            | Deploy paths and read, public               | `lib_layered_config.examples.deploy`                                                                        | `deploy_config_paths` equals what a forced deploy reports writing (with and without a profile); `read_deploy_config` leaves out the `skip` files in any spelling, refuses a broken file not left out, never reads `.env`, keeps only a user file's `user_*` modes, follows a platform override, and refuses a single path as `skip`.                                                                                                                    |
| `tests/examples/test_deploy_permission_wall.py`        | Deploy source behind a permission wall      | `lib_layered_config.examples.deploy`, `adapters._path_probe`                                                | A deploy source, or a `.d` directory that can be listed but not entered, raises `PermissionError` on every Python and writes nothing; a missing source still raises `FileNotFoundError`. On Windows, a `%APPDATA%` that cannot be checked (`tests.support.windows_acl.stat_wall`) raises instead of falling back to `%LOCALAPPDATA%`.                                                                                                                   |
| `tests/e2e/test_cli_deploy_modes.py`                   | CLI mode options and configured permissions | `lib_layered_config.cli.deploy`                                                                             | `deploy` command: `--dir-mode`/`--file-mode`, `--permissions`/`--no-permissions` interactions, and configured permissions through `click.testing.CliRunner`.                                                                                                                                                                                                                                                                                            |
| `tests/e2e/test_env_dotenv_parity.py`                  | Environment/`.env` parity                   | `lib_layered_config.core`                                                                                   | An unquoted value, scalar or JSON array/object, reaches the configuration with the same type from the environment and from `.env` (quoted vs. unquoted, comma lists, per-index overrides).                                                                                                                                                                                                                                                              |
| `tests/adapters/test_dotenv_scalar_coercion.py`        | `.env` scalar conversion                    | `lib_layered_config.adapters.dotenv.default`, `adapters._value_coercion`                                    | An unquoted `.env` value converts exactly like the environment; a quoted one stays literal text; a sensitive key keeps `null`/`none` as text.                                                                                                                                                                                                                                                                                                           |
| `tests/adapters/test_sensitive_null_stays_text.py`     | Secret spelled `null`/`none`                | `lib_layered_config.adapters.env.default`, `adapters._value_coercion`                                       | A sensitive key (judged on its leaf segment) keeps an unquoted `null`/`none` as text; every other key reads it as None.                                                                                                                                                                                                                                                                                                                                 |
| `tests/adapters/test_yaml_non_string_keys.py`          | Non-string YAML keys refused                | `lib_layered_config.adapters.file_loaders.structured`                                                       | A YAML mapping key that is not a string refuses the whole file, naming the file, the key's position and the key, never a value.                                                                                                                                                                                                                                                                                                                         |
| `tests/adapters/test_yaml_ordered_map_tags.py`         | YAML `!!omap`/`!!pairs` refused             | `lib_layered_config.adapters.file_loaders.structured`                                                       | A YAML `!!omap` or `!!pairs` value with entries (tuples whose keys redaction cannot see) refuses the whole file, naming the file and each value's position, never a key or value from inside it; an empty one and a merge key still load.                                                                                                                                                                                                               |
| `tests/adapters/test_yaml_unserialisable_tags.py`      | YAML `!!set`/`!!binary` refused             | `lib_layered_config.adapters.file_loaders.structured`                                                       | A YAML `!!set` or `!!binary` value (a Python set or bytes, which no JSON view can carry) refuses the whole file, naming the file and each value's position and type, never the value; timestamps and dates still load and serialise.                                                                                                                                                                                                                    |
| `tests/adapters/test_loader_wide_int_refusal.py`       | Integer outside JSON's range refused        | `lib_layered_config.adapters.file_loaders.structured`                                                       | A TOML or YAML integer below -2**63 or above 2**64-1 (which no JSON view can write) refuses the whole file, naming the file and each integer's position and width, never its digits; every integer inside the range still loads.                                                                                                                                                                                                                        |
| `tests/e2e/test_json_depth_limit.py`                   | Config deeper than JSON output refused      | `lib_layered_config.adapters.file_loaders.structured`, `lib_layered_config.adapters._value_coercion`        | A TOML, JSON or YAML file nesting past 253 levels from the top-level table is refused, naming the file, key and depth; an environment or `.env` JSON value that deep stays text, the levels its key adds counted; at the limit every JSON view writes.                                                                                                                                                                                                  |
| `tests/e2e/test_env_undecodable_bytes.py`              | Environment value or name not UTF-8 refused | `lib_layered_config.adapters.env.default`                                                                   | A prefixed variable whose value or name holds a lone surrogate (POSIX's undecodable byte, Windows' unpaired surrogate) is refused, naming the variable and byte offset, never the value; variables outside the prefix and valid non-ASCII text are untouched.                                                                                                                                                                                           |
| `tests/adapters/test_loader_depth_refusal.py`          | Parser depth limit named                    | `lib_layered_config.adapters.file_loaders.structured`                                                       | A TOML, JSON or YAML file nested deeper than its parser allows is refused as nesting too deep, with the position when known; a malformed file is still called invalid.                                                                                                                                                                                                                                                                                  |
| `tests/unit/test_cli_read_toml_text.py`                | `read` output reads back as TOML            | `lib_layered_config.cli.common`, `adapters.display.toml_text`                                               | The `read` command quotes a key holding a dot, a space or `=`, a table header holding one, and a string holding a quote or backslash, so its output parses back to the configuration it shows; plain keys and values print as before.                                                                                                                                                                                                                   |
| `tests/unit/test_display_huge_int.py`                  | Huge int shown by its width                 | `lib_layered_config.adapters.display.toml_text`                                                             | `display_config` and the `read` rendering show an int past Python's 4300-digit text limit, in a caller-built `Config`, as `<int, N bits>` instead of raising; other ints print as before.                                                                                                                                                                                                                                                               |
| `tests/domain/test_json_codec.py`                      | JSON codec parity                           | `lib_layered_config.domain.json_codec`                                                                      | Every case runs on each codec the interpreter has: wide ints, NaN/Infinity, lone surrogates, depth bounds to read and write, compact and indented output, and a hypothesis round trip comparing the stdlib codec with orjson; a free-threaded interpreter never imports orjson.                                                                                                                                                                         |
| `tests/adapters/test_toml_backend.py`                  | TOML parser parity                          | `lib_layered_config.adapters.file_loaders._toml_backend`                                                    | Every case runs on each TOML parser the interpreter has (rtoml, tomli, tomllib): the five nesting forms at rtoml's limit and far past it, the array and table depth bounds, malformed documents including a float past the float range, a byte order mark, positions, values, dates and times, the wide-int refusal through the loader, a corpus read through load-then-merge compared with rtoml, TOML 1.1 on the chosen parser, and parser selection. |
| `tests/adapters/test_dotenv_explicit_special_files.py` | `.env` from a FIFO or device                | `lib_layered_config.adapters.dotenv.default`, `cli.read`                                                    | `read_config(dotenv_path=...)` and `read --env-file` read a FIFO (a shell process substitution), refuse an endless device at the size cap, and keep a missing path an empty layer.                                                                                                                                                                                                                                                                      |
| `tests/adapters/test_env_scalar_coercion.py`           | Environment and `.env` scalar conversion    | `lib_layered_config.adapters._value_coercion`                                                               | An unquoted value converts to bool, null, int or float only when it reads back losslessly; an int below -2**63 or of more than 19 digits stays text.                                                                                                                                                                                                                                                                                                    |
| `tests/e2e/test_free_threaded_smoke.py`                | Concurrent reads, GIL kept off              | `lib_layered_config.core`                                                                                   | 16 threads x 20 `read_config` calls equal the single-threaded result; on a free-threaded build the GIL stays off and neither orjson nor rtoml is imported.                                                                                                                                                                                                                                                                                              |

When adding a new feature, update this matrix and the relevant module reference
entry so test intent stays visible to readers and reviewers.
