# Module Reference

An architecture map of `lib_layered_config`: the layers, the import rules the build enforces,
and a one-line responsibility for every module. The exhaustive per-function detail (arguments,
return types, edge cases, runnable examples) lives in the source docstrings - Google style,
type-checked by pyright and executed as doctests under `make test` - so this file stays the
orientation layer on top of them rather than a second copy that rots. For the design intent see
[concept.md](concept.md); for user-facing usage see the [README](../../README.md) and the guides
under [docs/](../).

## Architecture

The library follows Clean Architecture: dependencies point inward only. Two import-linter
contracts in `pyproject.toml` (run by `lint-imports`, and in CI) fail the build if either is
violated:

- **Layered:** `cli` -> `examples` -> `deploy` | `generate` -> `adapters` -> `application` ->
  `domain`. A layer may import only from the layers below it; `deploy` and `generate` share one
  layer and may not import each other.
- **Domain is pure:** `domain` may not import `adapters`, `application`, or `core`.

The root modules (`core.py`, `_layers.py`, `_platform.py`, `observability.py`, `testing.py`,
`__init__.py`, `__init__conf__.py`, `__main__.py`) sit outside the layer hierarchy and act as the
composition root and shared plumbing.

### The read pipeline

`read_config(...)` resolves per-platform paths, loads each layer, and deep-merges them in a fixed
precedence, producing an immutable `Config` plus provenance:

```
defaults -> app -> host -> user -> dotenv -> env      (lowest to highest precedence)
```

Every merged value records which layer and file produced it; `Config.origin(key)` returns that.

## Module map

### Composition root and shared plumbing

| Module              | Responsibility                                                                                                                                                                                                                                                                                                                |
|---------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `__init__.py`       | Public API surface: re-exports the read functions, `Config`, `Layer`, deploy/generate, and the validation and permission constants.                                                                                                                                                                                           |
| `__init__conf__.py` | Generated package-metadata constants, synced from `pyproject.toml`.                                                                                                                                                                                                                                                           |
| `__main__.py`       | `python -m lib_layered_config` entry point; delegates to the CLI.                                                                                                                                                                                                                                                             |
| `core.py`           | Composition root: `read_config` / `read_config_json` / `read_config_raw` wire the adapters and the merge; defines `LayerLoadError`; `read_config_for_deploy` reads the merged configuration `deploy_config` uses to resolve configured permission modes.                                                                      |
| `_layers.py`        | Layer assembly: `collect_layers` yields the `LayerSnapshot`s in order (defaults, app, host, user, dotenv, env), incl. `.d` and dotenv, one parsed file at a time; `collect_deploy_layers` yields the same for `read_config_for_deploy`, skipping the files a deploy call writes; `merge_or_empty` merges them as they arrive. |
| `_platform.py`      | Normalizes user-supplied platform aliases (`normalise_resolver_platform`, `normalise_examples_platform`); raises `ValidationError`.                                                                                                                                                                                           |
| `observability.py`  | Structured logging helpers (`log_debug`/`log_info`/`log_warn`, trace-id binding) so adapters log without coupling the domain.                                                                                                                                                                                                 |
| `testing.py`        | Small diagnostics helper (`i_should_fail`) for consumers' failure-path tests and the CLI `fail` command.                                                                                                                                                                                                                      |

### domain/ - pure business logic (no I/O)

| Module                  | Responsibility                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
|-------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `config.py`             | Immutable `Config` value object: dotted-path `get`/`__getitem__`, `origin` provenance lookup, `as_dict`/`to_json` (optional redaction), `get_redacted`; carries the application's `NotSensitiveKeys`; `SourceInfo`.                                                                                                                                                                                                                                                                                                                                                                      |
| `errors.py`             | Exception taxonomy: `ConfigError` base, `InvalidFormatError`, `ValidationError` (subclasses `ConfigError` and `ValueError`), `DeployDestinationError` (a linked or non-regular deploy destination), `GenerateDestinationError` (the same for an example path generate would write through), `LayerRootNotAbsoluteError` (a layer root that is not absolute: a Windows root, an empty or relative `HOME` or `USERPROFILE`, an empty or relative `LIB_LAYERED_CONFIG_*` root), `HomeDirectoryUnknownError` (no home directory for the user layer; also a `RuntimeError`), `NotFoundError`. |
| `identifiers.py`        | `Layer` enum and identifier/profile validation (path traversal, reserved names, control chars, non-ASCII, length); raises `ValidationError`.                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `redaction.py`          | Secret masking: `is_sensitive` (password/pass/pwd/token/apikey/`_key`/bearer/cookie/jwt/... patterns), URL passwords in values, `redact_mapping(not_sensitive=...)` (depth-guarded), `NotSensitiveKeys` (app-declared exemptions), `is_sensitive_at`, `redact_value_at` (one value as the whole view shows it, walking only its path), `REDACTED_PLACEHOLDER`.                                                                                                                                                                                                                           |
| `printable.py`          | `escape_controls`: a key, path or refused value inside one human line, its control characters as `\uXXXX`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `permissions.py`        | Per-layer Unix permission policy: `LAYER_PERMISSIONS` (read-only, keyed by `Layer`, each a `DefaultLayerModes(directory, file)`), mode constants, `apply_mode` / `modes_apply`.                                                                                                                                                                                                                                                                                                                                                                                                          |
| `deploy_mode.py`        | `DeployMode`/`ModeKind`/`DeployModeError`: the one rule for a safe deploy mode; `parse_mode_text`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `deploy_permissions.py` | `DeployPermissions`/`LayerModes`: per-layer modes and `enabled`, read from `[lib_layered_config.default_permissions]` in one pass with one-line problems, runtime overrides laid over it; `drop_app_and_host_modes` strips what a user-layer file may not decide.                                                                                                                                                                                                                                                                                                                        |
| `json_codec.py`         | JSON reading and writing for every JSON view and the JSON loader: `OrjsonCodec` below Python 3.14, `StdlibCodec` on 3.14+ and free-threaded builds (chosen once as `CODEC`); the stdlib codec refuses what orjson refuses (depth past 1024 to read and 254 to write, NaN/Infinity, lone surrogates on read, ints outside 64 bits on write) and reads a wide int as a float; on write both codecs escape a lone surrogate (`escape_lone_surrogates`: a POSIX byte that is not UTF-8 as `\xNN`); `JsonLoadError` carries the position and whether the input nests too deep.                |
| `source_position.py`    | `SourcePosition`: the 1-based line and column where a TOML, JSON or YAML parser stopped, a `NamedTuple` so it unpacks and compares like a plain tuple.                                                                                                                                                                                                                                                                                                                                                                                                                                   |

| Module     | Responsibility                                                                                                                                                                                 |
|------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|

### adapters/ - infrastructure

| Module                                               | Responsibility                                                                                                                                                                                                                                                                                                                                                                                                                  |
|------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `_nested_keys.py`                                    | Shared `__`-delimited nested-key placement (`build_nested`) used by the dotenv and env loaders; refuses a key with an empty segment.                                                                                                                                                                                                                                                                                            |
| `_value_coercion.py`                                 | `coerce_value`, the one conversion the env and dotenv loaders apply to an unquoted value (bool/null, JSON array/object via `parse_json_container`, lossless int/float via `parse_number`); a sensitive key keeps `null`/`none` as text.                                                                                                                                                                                         |
| `_stream_text.py`                                    | `fit_json` / `fit_text`: text fitted to a stream's encoding, a character it cannot encode written as a `\uXXXX` JSON escape or a Python backslash escape; `FittedStream` / `fitted_console_file`: a stream for a Rich `Console` that does the same on every write, answering `encoding`, `isatty` and `fileno` for the current stdout. Used by the CLI's `output.py` and `display_config`.                                      |
| `_text_decoding.py`                                  | `decode_utf8` / `decode_yaml_text`: decode file bytes, refusing content-free on failure (path, line, byte offset); `decode_yaml_text` also honors a YAML file's UTF-16/UTF-32 byte-order mark. `UTF8_BOM_CHAR` is the leading UTF-8 byte-order mark the TOML and `.env` readers drop.                                                                                                                                           |
| `_path_probe.py`                                     | `probe_path` / `checked_kind`: classify a path from `Path.stat()` the same on every Python; the `.env` search skips what it cannot check, other reads refuse it (`config_path_unreadable`); `current_directory` is the working directory, or `None` when the OS cannot name it. `is_symlink_or_raise` / `lexists_or_raise` look at a name itself, a link not followed (deploy's destinations and sidecar names).                |
| `_file_write.py`                                     | `write_file`: deploy's writes go to a temp file beside the destination, renamed into place, so a failed write leaves the old file; with permission setting off the new file takes the old one's mode, and `must_write_in_place` keeps a destination a rename would change (hard links, owner or group, not writable, extended attributes differing from a new file's by name or value) on an in-place write.                    |
| `_windows_acl.py`                                    | `copy_dacl`: on Windows, give a new file the DACL of the file it replaces or copies (protected or inherited as it was, owner not copied) before `write_file` renames it into place and after `deploy` backs a file up; nothing off Windows, for a source that does not exist, or on a volume without access lists.                                                                                                              |
| `path_resolvers/default.py`                          | `DefaultPathResolver`: selects a per-OS strategy and yields ordered candidate paths per layer.                                                                                                                                                                                                                                                                                                                                  |
| `path_resolvers/_base.py`                            | `PlatformContext`, the `PlatformStrategy` base, and `collect_layer` (a config file plus its `.d`).                                                                                                                                                                                                                                                                                                                              |
| `path_resolvers/_linux.py` `_macos.py` `_windows.py` | Per-platform directory layouts (XDG, Application Support, ProgramData).                                                                                                                                                                                                                                                                                                                                                         |
| `path_resolvers/_dotenv.py`                          | Ordered `.env` search-path discovery.                                                                                                                                                                                                                                                                                                                                                                                           |
| `file_loaders/structured.py`                         | TOML / JSON / YAML loaders (`BaseFileLoader`), with a maximum-file-size guard and `read_capped_bytes` for a FIFO or device; the TOML and JSON loaders take their parser as a constructor argument; reports an unparsable file's place and reason, never its content.                                                                                                                                                            |
| `file_loaders/_toml_backend.py`                      | TOML parsing: `RtomlParser` below Python 3.14, `TomliParser` (tomli on 3.14, tomllib on 3.15+) on 3.14+ and free-threaded builds (chosen once as `PARSER`); `TomliParser` skips a BOM, refuses a float past the float range, tables past `TOML_MAX_TABLE_DEPTH` (101, the merge's bound) and directly nested arrays past `TOML_MAX_ARRAY_DEPTH` (80); `TomlLoadError` carries the position and whether the file nests too deep. |
| `file_loaders/_yaml_facade.py`                       | Typed facade for the optional PyYAML module: the `YAMLModule` Protocol (`safe_load`, `compose`, `SafeLoader`, `YAMLError`), the `YAMLNode` / `YAMLMark` node graph the key checks read, and the two narrowing points `as_yaml_module` and `compose_document`.                                                                                                                                                                   |
| `file_loaders/_dot_d.py`                             | `.d` directory expansion (`expand_dot_d`), filtered by config extension.                                                                                                                                                                                                                                                                                                                                                        |
| `dotenv/default.py`                                  | `DefaultDotEnvLoader`: parse a `.env` file via upward search or an explicit path; unquoted values converted by `_value_coercion.coerce_value`.                                                                                                                                                                                                                                                                                  |
| `env/default.py`                                     | `DefaultEnvLoader`: prefix-filter environment variables and nest values converted by `_value_coercion.coerce_value`.                                                                                                                                                                                                                                                                                                            |
| `display/rich.py`                                    | Rich-styled human rendering of the merged configuration, walked as a mapping (never re-parsed TOML), with per-key provenance comments.                                                                                                                                                                                                                                                                                          |
| `display/toml_text.py`                               | TOML text for a key, a dotted key path and a value, shared by `display_config` and the `read` command so both quote keys, headers and strings the same way and their output reads back as the TOML it shows.                                                                                                                                                                                                                    |

### deploy.py and generate.py - deployment and scaffolding (one layer between cli and adapters)

`examples/` above them is a deprecated shim: importing `lib_layered_config.examples`,
`.examples.deploy` or `.examples.generate` warns (`DeprecationWarning`) and re-exports the same
objects from these two modules. It is removed in the next major release.

| Module        | Responsibility                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
|---------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `deploy.py`   | `deploy_config` and the per-OS `DeploymentStrategy`; conflict handling (backup `.bak`, keep-as-`.ucf`), atomic writes, and layer permission hardening; `DeployAction`, `DeployResult`; resolves each layer's modes (explicit, configured, built-in) and reads the configured section when it matters, never from `.env` or the files it writes; `deploy_config_paths` (the files a deploy writes) and `read_deploy_config` (its read, with chosen files left out) expose both to callers; an error raised partway carries the results already written, read back with `deployed_before_failure`. |
| `generate.py` | Scaffold example config trees (`generate_examples`, `generate_examples_report` / `ExamplesReport`, `ExamplePlan`, `ExampleSpec`); an error raised partway carries the examples already written, read back with `generated_before_failure`.                                                                                                                                                                                                                                                                                                                                                       |
